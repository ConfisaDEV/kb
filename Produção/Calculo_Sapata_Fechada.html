Neste artigo veremos como é o cálculo de sapatas fechadas no sistema Confisa ERP.


A sapata fechada, a qual se assemelha a um quadrado ou retângulo normalmente, possui cálculos distintos em casos onde o comprimento e largura são iguais ou diferentes.

Caso o comprimento seja igual à largura, o sistema utiliza a fórmula (Largura * 2 + Altura * 2) + 10 cm para cada camada.

Ex: 520 cm de largura, 50 cm de altura com 14 ferros por camada, contendo duas camadas.

(520 cm  x2 + 50 cm x2 ) + 10 cm para cada camada para amarração, totalizando 11,50 metros.

Já quando a sapata é retangular, onde o comprimento é diferente da largura, o sistema faz o cálculo de camadas duas vezes, uma para o comprimento e outra para a largura.

Ex: 520 cm de comprimento, 500 cm de largura, 50 cm de altura com 14 ferros por camada, contendo duas camadas.

(520 cm  x2 + 50 cm x2 ) + 10 cm para cada camada para amarração, totalizando 11,50 metros.
(500 cm  x2 + 50 cm x2 ) + 10 cm para cada camada para amarração, totalizando 11,10 metros.
